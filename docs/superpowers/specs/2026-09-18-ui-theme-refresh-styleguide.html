UI theme refresh — style guide v2 (refined per feedback)

Theme:

00 — Design critique (self-review pass)

Typography was the biggest gap — every other lever moved (color, radius, shadow, spacing) but type never did. Fixed by giving the brand wordmark the app's existing display face (§08's sidebar), the one place personality is safe to keep on purpose while everything functional gets quieter. Everything else stays on the app's existing Inter/JetBrains Mono pairing — untouched, not overlooked.

Soft glow vs. hard shadow was an unresolved tension in the first "active" panel: a thick pastel ring next to a bold graphic offset shadow is two different design languages fighting for attention. Fixed by thinning the ring to 1.5px and letting the hard shadow stay the dominant, confident move — the ring's job is just to say "this one," not to compete.

Chips were speculative until wired into §08's agent roster (status, replacing a bare dot) — a pattern doesn't belong in a shipped system until it's proven useful somewhere real.

The new primary accent was too close to the existing `lilac` agent-identity hue, especially in dark mode — caught by checking it against the existing six accents rather than in isolation, and pulled further toward blue for real separation.

Not resolved here, flagged for a real decision: whether the 2D floor's frame (not the tileset or characters — those stay untouched) should get the same rounded/grounded treatment as the rest of the UI. See the chat discussion; not yet scoped into this spec.

05 — PixelPanel variants: redesigned

Fixed live, found in the running app: the dialog header (cream-200) on a near-white dialog body (cream-50) read as a smudge/glitch, not a header — too close to match, too different to ignore. The header now always matches its own panel's fill exactly; the divider + dot carry the "this is a header" signal instead of a color block.

Changed: title strip is now a quiet header row with a small status dot instead of a heavy painted block; "active" is a soft accent glow ring instead of a thick 3-layer painted border — reads as "selected," not "boxed in." Fixed: v2 had a corner-seam glitch on inset/dialog panels because the header rounded its own corners independently of the panel — two separately-computed curves that don't perfectly align. Fixed by giving the panel `overflow:hidden` as the single source of the rounded shape; the header is now a plain rectangle clipped to it, and its fill is back to `cream-200` (matching the old version's contrast) instead of v2's too-similar `paper-200`.

06 — Buttons & hover

Changed: kept the exact old hover mechanic (fill + hard offset + 1px lift) — only recolored, from lemon to a new dedicated --cth-primary. Started from the "Share" button in your dev-tool toolbar reference, then pulled toward blue and away from violet after checking it against the existing --cth-lilac agent hue — the two were too close, especially in dark mode. Final: #4F68E8 light / #7B93F5 dark, distinct from every agent/status color.

Tab to the last button to see focus-visible — unchanged from the app's existing keyboard-focus ring, carried forward on purpose.

07 — Chips

Used in section 08's agent roster for status, replacing a bare color dot with a labeled chip — a pattern shouldn't ship in a system without appearing somewhere real.
