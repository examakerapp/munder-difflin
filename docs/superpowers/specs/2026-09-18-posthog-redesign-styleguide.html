00 — What's sourced vs. approximated

SOURCED = pulled directly from PostHog's public open-source repo (frontend/src/styles/lemon-skin.scss, @posthog/quill's published primitives.css) on 2026-09-18 — radius scale, the brand orange accent (light + dark), and the six new agent-identity colors (from their real 15-color categorical data-viz palette).

APPROXIMATED = their exact neutral-cool / posthog-3000 hex steps are compiled into a private/internal token source, not present in any published dist file I could reach — the base neutral scale below matches their documented STRUCTURE (cool blue-gray, white cards, same relative lightness steps our own ramp already contrast-verified) but is not a pixel-sampled exact match. Flagged here rather than presented as more certain than it is.

01 — Base neutral: warm → cool approximated

The single biggest structural change: our whole base (app background, cards, borders) moves from the warm cream/paper family to PostHog's cool blue-gray neutral. This is a bigger shift than the earlier pass, which only changed shade, not temperature.

02 — Six agent-identity accents: fully replaced sourced

Per your decision: these were previously out of scope (functional, already contrast-verified) but you chose a complete PostHog match, so all six are replaced with picks from PostHog's own published categorical palette — chosen for maximum separation and to stay clear of the brand-orange family.

03 — Brand primary: "Amber Glow" sourced

Replaces the indigo-blue --cth-primary from the last pass. Light: #EB9D2A — PostHog's actual primary CTA color, per your direct request over the orange-red I'd first pulled from an in-product token. Dark: lightened slightly (#F0B24E) for contrast against a dark ground, same reasoning this system already applies to every other accent in dark mode.

Button treatment added: a solid, hard-edged "pressed sticker" base under both buttons — not a blurred shadow, so it doesn't contradict "flat, no shadows" for panels. Buttons are things you press; a small tactile 3D cue there is legible and stays contained to interactive controls, matching the reference screenshot and the marketing extraction's own description of the Amber CTA as a "pressed paper sticker."

04 — Radius: unchanged sourced, already matched

PostHog's actual radius scale (4px / 6px / 10px) is nearly identical to what this app already adopted independently in the last pass — no change needed here.

Shadow: removed entirely, per direct feedback — this system is now fully flat. Every surface's edge comes from a 1px hairline border alone, with zero drop shadow anywhere, including the dialog/modal variant. A dimmed backdrop (not a shadow) is what would signal "this is on top" for an actual modal.
